# Security Policy

## Supported versions

Only the latest state of the default branch is supported. Fixes are not back-ported.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

1. Use GitHub's private reporting: **Security → Advisories → Report a vulnerability** on this repository.
2. Include: the affected file or endpoint, steps to reproduce, and the expected impact.
3. Never include real API keys or personal data in a report. If a secret was exposed, rotate it first.

You can expect an acknowledgement within a few days. Confirmed issues are fixed on the default branch and credited in the release notes, unless you prefer to stay anonymous.
